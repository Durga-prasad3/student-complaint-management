# SmartCampus Client

The React/Vite frontend for the SmartCampus complaint management project. It provides separate student, staff, and administrator experiences.

## Run the client

From this directory, install dependencies and start the development server:

```powershell
npm install
npm run dev
```

Other available commands are `npm run build`, `npm run preview`, and `npm run lint`.

For the full project overview, API and database setup, roles, and integration status, see the [project README](../README.md).
